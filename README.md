# Display Inline-block Layout

Bài thực hành tạo bố cục trang web với:

- `display: block` cho các vùng chính.
- `display: inline-block` cho liên kết và ba cột nội dung.
- `width: 32%` cho mỗi cột.
- `max-width: 1100px` để giới hạn độ rộng trang.
- Responsive: ba cột chuyển thành một cột trên màn hình nhỏ.

Mở `index.html` bằng trình duyệt để xem kết quả.
